# fileSense — AI-Powered Intelligent File Management System

**Intelligence for Your Files.**

fileSense is an AI-powered desktop file management application designed to help users search, organize, analyze, and manage files more intelligently. It combines file indexing, semantic search, duplicate detection, automated organization, and sensitive-data risk detection in a unified interface.

The goal is to make file management smarter, faster, and more secure while providing users with greater visibility into their local file system.

## ✨ Key Features

- **📊 Intelligent Dashboard** — View indexed files, storage usage, file categories, system insights, and organization recommendations.
- **🔎 Semantic Search** — Discover files using natural-language queries and meaning-based search rather than relying only on filenames.
- **🤖 AI File Organizer** — Organize files into structured groups based on categories or dates.
- **🛡️ Sensitive Data Detection** — Identify potentially exposed API keys, passwords, private keys, email addresses, phone numbers, and other sensitive information.
- **♻️ Duplicate Detection** — Find duplicate files and reduce unnecessary storage usage.
- **🧠 AI Assistant** — Interact with the file management system through an AI-oriented chat interface.
- **📁 File Categorization** — Group and analyze code files, documents, PDFs, images, archives, and other file types.
- **🗂️ File Management Tools** — Access similar files, storage information, activity timelines, and the recycle bin.
- **⚙️ Privacy Settings** — Configure local-only operation, semantic search, automatic indexing, and security-related preferences.

## ⚙️ How It Works

1. **Scan:** Select a folder and index its files.
2. **Analyze:** Collect file metadata and perform the analyses supported by the application.
3. **Search:** Find relevant files using conventional or semantic search.
4. **Organize:** Group files according to supported organization rules.
5. **Protect:** Scan supported text files for potentially sensitive information.
6. **Manage:** Review duplicates, storage usage, file activity, and organization insights.
